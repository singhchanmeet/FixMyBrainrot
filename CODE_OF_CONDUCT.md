# Code of Conduct

## Our standard

Everyone participating in this project is expected to be respectful, constructive, and considerate. Discussions should focus on the work and its impact rather than on individuals.

Unacceptable behavior includes harassment, discrimination, personal attacks, deliberate disruption, and publishing someone else's private information without permission.

## Enforcement

Project maintainers may remove comments, close discussions, or reject contributions that do not meet these standards. Reports can be made privately to the project maintainer through the contact details in [about.html](about.html).

## Scope

This code of conduct applies to project spaces, issue discussions, pull requests, and other interactions related to the project.
